# Personal Finance Manager

This small command-line tool helps you track monthly expenses and decide whether you can afford new purchases.

## Features
- Record your monthly income.
- Add, update, or remove expenses (e.g. subscriptions, loan payments, credit cards).
- View a summary of total expenses and leftover budget.
- Ask if you can afford an item before buying it.

## Usage
Make sure you have Python installed, then run:

```bash
python finance_manager.py
```

Follow the on-screen menu to manage expenses and check potential purchases.
